◆ ModulesMode

enum class truss::ModulesMode
exportstrong

How .cppm sources in a user target get compiled and wired.

Auto (the default): BMI edges for every .cppm; consumers are wired from a fast regex scan of each file's import declarations (heuristic: can miss macro-generated imports or false-positive on import in comments). Manual: same wiring but the import lists come from clang-scan-deps (p1689) at configure time — authoritative, at ~10 ms per TU; clang only.

Enumerator
Default 

resolves to Auto

Off 

no BMI wiring (.cppm sources become a Config error)

Auto 

BMI edges + regex-scanned import wiring (heuristic, fast).

Manual 

import lists from clang-scan-deps (authoritative, ~10 ms/TU, clang only)
