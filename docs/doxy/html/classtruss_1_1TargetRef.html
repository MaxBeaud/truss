Detailed Description

Non-owning handle to a target created by add_subdirectory()/conan()/vcpkg().

std::expected cannot hold T&, so this is the reference-shaped stand-in: never null, dereferenceable, and converts implicitly to Target& — depends_on(*proj.conan({"zlib/1.3.1"})) just works.
