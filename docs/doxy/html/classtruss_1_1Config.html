Detailed Description

Project-wide toolchain selection, applied with proj.configure(conf).

compiler()/linker() take a program name or a path; the compiler family is detected from the basename (clang++, g++, clang-cl, cl.exe, ...). toolchain() expands to compiler + stdlib + archiver in one call; later explicit calls override it (last call wins).

Config & truss::Config::launcher ( std::string name)
inline

Compiler cache launcher (e.g.

"ccache", "sccache") prefixed to compile commands; "" disables it. Default: auto-detect ccache then sccache on PATH. GCC/Clang families only (MSVC compile rules never use a launcher); module BMI rules are never launched (ccache's module support is unreliable).
