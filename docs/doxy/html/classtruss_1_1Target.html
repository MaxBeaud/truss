Detailed Description

A build target: options holder built with method chaining.

Every builder method returns Target& so calls chain; concrete kinds are Executable, StaticLib, SharedLib and Interface.

Precompiled header for this target's C++ sources.

Target & truss::Target::sources ( std::string_view pattern)
inline

Source glob patterns relative to the project root.

* matches within one path component, ** across components, ? one char, {a,b} alternation. e.g. "src/&zwj;**.cpp", "src/*.c". Overloads: single pattern, braced list, any range of strings.

Parameters
patternglob, or literal path (which must exist).
Returns
*this for chaining.

Target & truss::Target::unity ( bool v = true)

Unity build: concatenate this target's C/C++ sources into batch TUs (16 per batch) under build/{mode}/unity/{target}/, compiled instead of the originals.

Module units (.cppm) are never batched. Faster clean builds; coarser incremental rebuilds.

Parameters
vtrue to enable (default when called with no argument).
