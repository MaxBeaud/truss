Detailed Description

Host introspection + program lookup for build scripts.

The platform predicates are consteval (predefined macros): they describe the machine the build script is compiled on — truss's distribution model guarantees the same compiler builds the BMIs and the script — and work in if constexpr. The rest are runtime facts (env, PATH, syscalls).

Search for truss module BMI files in standard installation paths.

Searches in order: TRUSS_INSTALL_PREFIX (if set), same directory as the truss executable, .local/lib/truss (relative to cwd), ~/.local/lib/truss, /usr/local/lib/truss, /usr/lib/truss.
