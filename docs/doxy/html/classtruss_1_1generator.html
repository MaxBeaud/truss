Detailed Description

template<class T>
class truss::generator< T >

Synchronous coroutine generator (range-for compatible).

Shape adapted from cppcoro::generator (MIT, Lewis Baker). truss uses this instead of std::generator because libc++ still lacks the <generator> header (P2502R2, llvm/llvm-project#105226) while truss's own stdlib is libc++; when libc++ ships it this becomes an alias for std::generator and call sites are unchanged. Move-only; the coroutine produces values lazily on iteration.
